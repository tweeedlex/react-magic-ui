# Modal

A dialog on a sheet of frosted glass over a dimmed page. It springs in and fades out, like iOS 26 alerts and sheets. The glass is denser than on cards, so text stays readable over any background.

<Canvas of={ModalStories.Default} />

## Usage

```tsx
import { Modal, Button } from "react-magic-ui";
import { useState } from "react";

const [open, setOpen] = useState(false);

<Button onClick={() => setOpen(true)}>Delete photo</Button>

<Modal
  open={open}
  onOpenChange={setOpen}
  title="Delete photo?"
  description="This can't be undone."
  footer={
    <>
      <Button onClick={() => setOpen(false)}>Cancel</Button>
      <Button variant="prominent" destructive onClick={remove}>Delete</Button>
    </>
  }
/>
```

Anything you pass as `children` goes into the body, between the header and the footer, such as a form or a longer text. If the content is taller than the screen, the dialog scrolls inside itself.

## Guidelines

- Use a modal for a short decision or a small task that has to be done before going back to the page. For a passing message, use a [Toast](?path=/docs/toast--docs).
- Put two or three actions in the `footer`, with the main one last. They share the row in equal widths, as in iOS alerts. Make the main action `variant="prominent"`, and add `destructive` when it deletes something.
- If closing the modal would lose the user's input, pass `closeOnOverlay={false}` so a stray click outside doesn't close it.

## Props

All `<div>` props go to the dialog panel, and `ref` points to it.

- **open** _`boolean`_: shows the modal. Required.
- **onOpenChange** _`(open: boolean) => void`_: called with `false` when the user closes it.
- **onClose** _`() => void`_: called at the same moment, without an argument. Pass either one; with neither, there is no close button.
- **title** _`ReactNode`_: the heading, linked to the dialog with `aria-labelledby`.
- **description** _`ReactNode`_: a line under the title, linked with `aria-describedby`.
- **footer** _`ReactNode`_: the row of actions at the bottom.
- **size** _`"sm" | "md" | "lg"`_: max width 400, 520 or 680px. Default `"md"`.
- **closeOnOverlay** _`boolean`_: a click on the dimmed page closes it. Default `true`.
- **closeOnEsc** _`boolean`_: Escape closes it. Default `true`.
- **lockScroll** _`boolean`_: the page behind doesn't scroll while the modal is open. Default `true`.
- **enableLiquidAnimation** _`boolean`_: the spring in and fade out. With `false` it appears and disappears at once. Default `true`.
- **portalContainer** _`HTMLElement | null`_: where the modal is rendered. Default `document.body`.
- **tone**, **lens**: see [Glass](?path=/docs/glass--docs).

## Behaviour

- The modal is rendered in a portal, but it takes the theme and ink tone of the place where you declared it.
- When it opens, focus moves to the dialog, so screen readers start reading from the title.
- The dialog has `role="dialog"` and `aria-modal="true"`.
- With `prefers-reduced-motion` there is no animation; the modal simply appears and disappears.

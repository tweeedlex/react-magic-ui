# Input

A text field in a glass capsule, for search fields, forms and command bars.

<Canvas of={Input.Default} />

## Usage

```tsx
import { Input } from "react-magic-ui";
import { useState } from "react";

const [q, setQ] = useState("");

<Input
  placeholder="Search"
  leadingIcon={<SearchIcon />}
  value={q}
  onChange={(e) => setQ(e.target.value)}
/>
```

It is a real `<input>`, so it works with form libraries that use refs and native events, such as React Hook Form:

```tsx
<Input type="email" placeholder="Email" invalid={!!errors.email} {...register("email")} />
```

## Props

All `<input>` props (`type`, `value`, `onChange`, `name`, `autoComplete`…) go to the inner `<input>`. `ref` and `className` go there too.

- **size** _`"small" | "medium" | "large"`_: height 32, 44 or 52px. Default `"medium"`.
- **leadingIcon** _`ReactNode`_: an icon before the text, such as a magnifying glass.
- **trailingIcon** _`ReactNode`_: an icon or small control after the text, such as a clear button.
- **invalid** _`boolean`_: a red ring plus `aria-invalid`. Put the error message next to the field and link it with `aria-describedby`.
- **disabled** _`boolean`_
- **wrapperClassName** / **wrapperStyle**: class and style for the glass capsule, for example to set its width.
- **tone**, **lens**, **layer**: see [Glass](?path=/docs/glass--docs).

## Behaviour

- The capsule is a `<label>`, so clicking anywhere on it, icons included, focuses the field.
- When focused, the capsule shows an accent-coloured ring.
- Give the field a name: a visible `<label htmlFor>`, an `aria-label`, or at least a placeholder for search fields.

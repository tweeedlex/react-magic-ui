# Badge

Small glass capsule label, or the iOS red notification count.

#### Example

<Canvas of={BadgeStories.Default} />

## Usage

```ts
import { Badge } from "react-glass-ui";

const Example = () => {
  return (
    <>
      <Badge>Beta</Badge>
      <Badge tint="var(--rmu-blue)">New</Badge>
      <Badge variant="notification" aria-label="3 unread">3</Badge>
    </>
  );
};

export default Example;
```

#### Variants

- **default** - a glass label ("New", "Beta", a version). Pass `tint` to colour the glass.
- **notification** - solid red oval with a white count, for things that need attention.

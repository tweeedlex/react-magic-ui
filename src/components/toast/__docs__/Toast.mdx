# Toast

A short message on a glass card that slides in at the edge of the screen and leaves by itself after a few seconds. Use it to confirm an action ("Saved") or report something that happened in the background.

<Canvas of={ToastStories.Playground} />

## Setup

Put one `ToastProvider` near the root of the app. It sets the defaults and renders the toasts in a portal.

```tsx
import { ToastProvider } from "react-magic-ui";

<ToastProvider position="top-center" duration={4000}>
  <App />
</ToastProvider>
```

## Usage

Anywhere below the provider, call `showToast` from `useToast()`:

```tsx
import { useToast, Button } from "react-magic-ui";

const SaveButton = () => {
  const { showToast } = useToast();

  return (
    <Button
      variant="prominent"
      onClick={async () => {
        await save();
        showToast({ variant: "success", title: "Saved", description: "Your changes are live." });
      }}
    >
      Save
    </Button>
  );
};
```

`showToast` returns the toast's id. To remove a toast yourself, for example an "Uploading…" toast once the upload is done, keep the id and pass it to `dismissToast`:

```tsx
const { showToast, dismissToast } = useToast();

const id = showToast({ title: "Uploading…", duration: Infinity });
await upload();
dismissToast(id);
showToast({ variant: "success", title: "Uploaded" });
```

## Guidelines

- Keep it to a title and at most one short line. Toasts leave on their own, so don't put anything there the user must read or act on; use a [Modal](?path=/docs/modal--docs) for that.
- `variant` adds an icon: `"success"` (green check), `"error"` (red exclamation mark) or `"info"` (blue i). `"default"` has no icon.

## ToastProvider props

- **duration** _`number`_: time on screen in ms. Default `4000`.
- **position** _`"top-right" | "top-left" | "top-center" | "bottom-right" | "bottom-left" | "bottom-center"`_: where the toasts stack. Default `"top-right"`.
- **animation** _`"slide-from-right" | "slide-from-left" | "slide-from-bottom" | "scale"`_: how they come in and leave. Default `"slide-from-right"`.
- **enableLiquidAnimation** _`boolean`_: animate toasts in and out. Default `true`.
- **portalContainer** _`HTMLElement | null`_: where the toasts are rendered. Default `document.body`.

## useToast()

- **showToast(toast)**: shows a toast and returns its id.
- **dismissToast(id)**: removes one toast.
- **clearToasts()**: removes all toasts.
- **defaults**: the provider's settings.

`useToast` throws an error if there is no `ToastProvider` above it.

## showToast options

- **title** / **description** _`ReactNode`_
- **variant** _`"default" | "success" | "error" | "info"`_: default `"default"`.
- **duration** _`number`_: ms on screen. `Infinity` keeps the toast until it is closed.
- **position**, **animation**, **enableLiquidAnimation**: override the provider's defaults for this toast.
- **id** _`string`_: your own id instead of a generated one.
- **onClose** _`() => void`_: called once when the toast starts to leave, whether by its timer, the close button or `dismissToast`.

## Behaviour

- The newest toast appears closest to the screen edge and pushes older ones away from it.
- Each toast has a close button and `role="status"` with `aria-live="polite"`, so screen readers announce it without interrupting.
- With `prefers-reduced-motion` toasts appear and disappear without sliding.

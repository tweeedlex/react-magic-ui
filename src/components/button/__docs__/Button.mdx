# Button

A capsule of liquid glass. On press it swells, springs back and lights up from the point you touched, like buttons in iOS 26.

<Canvas of={Button.Glass} />

## Usage

```tsx
import { Button } from "react-magic-ui";

<Button onClick={cancel}>Cancel</Button>
<Button variant="prominent" onClick={save}>Done</Button>
<Button destructive onClick={remove}>Delete</Button>
<Button rounded aria-label="Add"><PlusIcon /></Button>
```

## Styles

iOS 26 has two button styles, and so does `Button`:

- **`"glass"`** (default): clear glass. Use it for most buttons.
- **`"prominent"`**: glass tinted with the accent colour. Use it for the one main action on a screen or in a bar, such as Done or Save.

<Canvas of={Button.Prominent} />

Use `destructive` for actions that delete or remove something. It gives a red label on glass and a red tint on prominent.

<Canvas of={Button.Destructive} />
<Canvas of={Button.DestructiveProminent} />

Use `tint` for any other colour, for example a green Answer button. On a prominent button it colours the glass; on a glass button it colours the label.

<Canvas of={Button.Tinted} />

Use `rounded` for a circular icon button. Give it an `aria-label`, since there is no text to read out.

## Props

All `<button>` props are passed through, and `ref` points to the `<button>`. `type` defaults to `"button"`, so a button in a form doesn't submit it by accident.

- **children** _`ReactNode`_: the label, or an icon. `text` also works and is kept for older code.
- **variant** _`"glass" | "prominent"`_: default `"glass"`.
- **destructive** _`boolean`_: red role for deleting or removing. Overrides `tint`.
- **tint** _`string`_: any CSS colour. Default is the accent (`--rmu-accent`, system blue).
- **size** _`"small" | "medium" | "large"`_: height 32, 44 or 52px. Default `"medium"`.
- **rounded** _`boolean`_: circle instead of capsule.
- **enableClickAnimation** _`boolean`_: the press spring and glow. Default `true`.
- **material**, **tone**, **lens**: glass options, see [Glass](?path=/docs/glass--docs).

## Behaviour

- A press scales the button up and adds a glow at the touch point. With `prefers-reduced-motion` the scale is off and only the glow fades in.
- `disabled` dims the button and turns off hover, press and clicks.
- Inside a [Card](?path=/docs/card--docs) or a bar, the button is drawn as an inner layer, so you never get glass blurred on top of glass.

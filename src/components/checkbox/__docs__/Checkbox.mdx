# Checkbox

A glass box with rounded corners. When checked, it fills with the accent colour and the check mark is drawn in.

<Canvas of={Checkbox.Default} />

## Usage

```tsx
import { Checkbox } from "react-magic-ui";
import { useState } from "react";

const [remember, setRemember] = useState(false);

<Checkbox label="Remember me" checked={remember} onCheckedChange={setRemember} />
```

## Checkbox or Switch?

- **Checkbox**: a choice in a form or a list that takes effect later, when the user saves or submits, for example "Send me updates" or picking several rows.
- **[Switch](?path=/docs/switch--docs)**: a setting that changes immediately, for example Wi-Fi.

## Props

All `<button>` props are passed through, and `ref` points to the `<button role="checkbox">`.

- **checked** _`boolean`_: the state when controlled.
- **defaultChecked** _`boolean`_: the starting state when uncontrolled. Default `false`.
- **onCheckedChange** _`(checked: boolean) => void`_: called with the new state. `onChange` still works but is deprecated.
- **label** _`ReactNode`_: text next to the box. Clicking it toggles the box too.
- **size** _`"small" | "medium" | "large"`_: box size 18, 22 or 26px. Default `"medium"`.
- **disabled** _`boolean`_
- **id**: goes to the box. It is generated if you don't pass one, and the `label` is linked to it.

## Behaviour

- Space toggles it, like any button. `aria-checked` follows the state.
- Without a `label`, give it an `aria-label`.

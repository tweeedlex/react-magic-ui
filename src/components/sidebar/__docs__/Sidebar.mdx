# Sidebar

A glass column for an app's main navigation. The selected item is highlighted, and the column can collapse to icons only. It is built from parts: `Sidebar.Header`, `Sidebar.Items`, `Sidebar.Item`, `Sidebar.Footer` and `Sidebar.Toggle`.

<Canvas of={SidebarStories.Default} />

## Usage

```tsx
import { Sidebar, Badge } from "react-magic-ui";
import { useState } from "react";

const [page, setPage] = useState("home");

<Sidebar collapsible activeItemId={page} onSelectItem={setPage}>
  <Sidebar.Header>
    <strong>Magic UI</strong>
    <Sidebar.Toggle />
  </Sidebar.Header>

  <Sidebar.Items>
    <Sidebar.Item itemId="home" icon={<HouseIcon />}>Home</Sidebar.Item>
    <Sidebar.Item itemId="inbox" icon={<TrayIcon />} badge={<Badge variant="notification">3</Badge>}>
      Inbox
    </Sidebar.Item>
    <Sidebar.Item itemId="settings" icon={<GearIcon />}>Settings</Sidebar.Item>
  </Sidebar.Items>

  <Sidebar.Footer>
    <small>v2.0</small>
  </Sidebar.Footer>
</Sidebar>
```

Without `activeItemId`, the sidebar keeps track of the selection itself. Pass `defaultActiveItemId` to choose the item selected at first.

## Collapsing

With `collapsible`, `Sidebar.Toggle` shows a button that narrows the column to 72px. Items then show only their icons; an item without an icon shows the first letter of its label, or `collapsedFallback` if you pass one. The header and footer hide everything except the toggle.

<Canvas of={SidebarStories.Collapsed} />

To control it yourself, for example to collapse it on small screens, pass `collapsed` and `onToggle`.

## Props

### Sidebar

All `<aside>` props are passed through, and `ref` points to the `<aside>`.

- **size** _`"small" | "medium" | "large"`_: width 200, 260 or 320px. Default `"medium"`.
- **collapsible** _`boolean`_: lets `Sidebar.Toggle` collapse it. Default `false`.
- **collapsed** / **defaultCollapsed** _`boolean`_: the collapsed state, controlled or uncontrolled.
- **onToggle** _`(collapsed: boolean) => void`_: called with the new collapsed state.
- **activeItemId** / **defaultActiveItemId** _`string`_: the selected item's `itemId`, controlled or uncontrolled.
- **onSelectItem** _`(itemId: string, event) => void`_: called when an item is clicked.
- **material**, **tone**, **lens**: see [Glass](?path=/docs/glass--docs).

<Canvas of={SidebarStories.Large} />

### Sidebar.Item

A `<button>`; all button props are passed through.

- **itemId** _`string`_: identifies the item. Required.
- **icon** _`ReactNode`_: shown before the label, and alone when collapsed.
- **badge** _`ReactNode`_: shown at the end, for example a [Badge](?path=/docs/badge--docs) with a count. Hidden when collapsed.
- **collapsedFallback** _`ReactNode`_: what to show when collapsed and there is no icon.
- **disabled** _`boolean`_

<Canvas of={SidebarStories.WithBadges} />

### Sidebar.useSidebar()

Returns `{ size, collapsed, collapsible, toggleCollapsed, activeItemId }`, so your own parts can react to the sidebar's state, for example to hide a label when it is collapsed.

## Behaviour

- The selected item gets `aria-current="page"`.
- The items are inside a `<nav>`, so screen readers list them as navigation.
- An item whose label is plain text uses that text as its `aria-label`, so it still has a name when collapsed to an icon.
- The toggle's label switches between "collapse sidebar" and "expand sidebar".

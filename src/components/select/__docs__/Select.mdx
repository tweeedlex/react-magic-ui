# Select

A glass button that opens a menu of choices. As in iOS 26, the menu grows out of the button and shrinks back into it when it closes.

<Canvas of={Select.Default} />

## Usage

```tsx
import { Select } from "react-magic-ui";
import { useState } from "react";

const [size, setSize] = useState("m");

<Select
  aria-label="Size"
  options={[
    { value: "s", label: "Small" },
    { value: "m", label: "Medium" },
    { value: "l", label: "Large", disabled: true },
  ]}
  value={size}
  onValueChange={setSize}
/>
```

In a form, pass `name`. A hidden input then holds the value, so it is submitted with the `<form>`:

```tsx
<form action="/save">
  <label htmlFor="size">Size</label>
  <Select id="size" name="size" options={options} defaultValue="m" />
</form>
```

## Props

- **options** _`{ value: string; label: ReactNode; disabled?: boolean }[]`_: the choices. Required.
- **value** _`string`_: the selection when controlled.
- **defaultValue** _`string`_: the starting selection when uncontrolled.
- **onValueChange** _`(value: string) => void`_: called with the chosen `value`. `onChange` still works but is deprecated.
- **onOpenChange** _`(open: boolean) => void`_: called when the menu opens or closes.
- **placeholder** _`string`_: shown while nothing is selected. Default `"Select an option"`.
- **name** _`string`_: field name for forms.
- **size** _`"small" | "medium" | "large"`_: height 32, 44 or 52px. Default `"medium"`.
- **disabled** _`boolean`_
- **id**, **aria-label**, **aria-labelledby**: these go to the button. Give the select a name with one of them.
- **className**, **style**, **tone**, **lens**. `ref` points to the button.

## Behaviour

- The menu opens below the button. It is rendered in a portal on `document.body`, so a parent with `overflow: hidden` can't cut it off.
- **Keyboard**: Enter, Space and the up and down arrows open the menu. The arrows move through the options, skipping disabled ones. Enter or Space picks an option, and Escape or Tab closes the menu.
- The button has `aria-haspopup="listbox"` and `aria-expanded`. Each option has `role="option"` and `aria-selected`.
- A click outside the menu closes it. With `prefers-reduced-motion` the grow animation is off.

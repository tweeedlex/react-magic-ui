# Slider

Picks a number in a range by dragging a knob along a glass track. While you drag, the knob grows into a clear glass bubble and the track fills with the accent colour.

<Canvas of={Slider.Default} />

## Usage

```tsx
import { Slider } from "react-magic-ui";
import { useState } from "react";

const [volume, setVolume] = useState(40);

<Slider aria-label="Volume" value={volume} onValueChange={setVolume} />
```

With a step and the value shown:

```tsx
<Slider aria-label="Opacity" min={0} max={100} step={10} defaultValue={50} showValue />
```

<Canvas of={Slider.StepTen} />

## Props

All `<div>` props are passed through to the root.

- **value** _`number`_: the value when controlled.
- **defaultValue** _`number`_: the starting value when uncontrolled. Default `50`.
- **onValueChange** _`(value: number) => void`_: called while dragging and on each keyboard step. `onChange` still works but is deprecated.
- **min** / **max** / **step** _`number`_: default `0`, `100`, `1`.
- **size** _`"small" | "medium" | "large"`_: track thickness and knob size. Default `"medium"`.
- **showValue** _`boolean`_: shows the number after the track.
- **disabled** _`boolean`_
- **aria-label** / **aria-labelledby**: the slider's name. One of them is required.
- **tone**: ink colour, see [Glass](?path=/docs/glass--docs).

## Behaviour

- Click anywhere on the track to jump there, or drag the knob.
- **Keyboard**: arrow keys move one step, Page Up / Page Down move a tenth of the range, Home / End go to the minimum / maximum.
- The knob has `role="slider"` with `aria-valuemin`, `aria-valuemax` and `aria-valuenow`.
- With `prefers-reduced-motion` the knob doesn't grow; it only changes look.
